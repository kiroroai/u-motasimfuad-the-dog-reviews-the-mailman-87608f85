Entry for make.fun's [The Dog Reviews the Mailman](https://make.fun/bounty/u-motasimfuad-the-dog-reviews-the-mailman-87608f85): one funny one-line review, under 200 characters, that a dog gives the mailman.

`main.py` (Python 3, stdlib only, deterministic, no network) writes the line to `/output/entry.txt`:

> One star for never letting me sniff the bag, five stars for the biscuit he slips through the gate, same time tomorrow, pal, I've nearly got him trained.

## Run it

```sh
python3 main.py
```
